# chr1 literal entropy layer — 64 KiB vs 16 KiB (2026-09-18)

This is the requested coarse literal-layer control on the full hg38 chr1 archive.
It is not a production format change.

Common to both rows: ACEAPEX `dbbb8b774bfe4933d40a3f39d357dc9598947a70`,
zstd `f8745da6ff1ad1e7bab384bd1f9d742439278e99`, g=R=16 KiB,
`FSE_CHUNK=4096`, `MIN_MATCH` unset, same unmodified
`aceapex_decompress_region` decoder, same ARM Neoverse-N2 runner class.
Both archives restored byte-perfect before timing.

The current production encoder rejects explicit `LIT_CHUNK<65536`; therefore the
16 KiB archive was made by a private encoder copy with exactly one source change:
the explicit environment floor was lowered from 64 KiB to 16 KiB. Production
ACEAPEX source was not modified.

## Literal-layer cut

With block size, request size, FSE granularity and the public decoder held fixed,
moving literal entropy checkpoints from 64 KiB to 16 KiB removes about **28.7% of
retired instructions** and **27.3% of cycles** from the current interactive path.
Wall p50 improves by **14.9%** on this runner.

The density price is much larger than the earlier FSE 512 KiB→4 KiB move:
complete ratio falls by **3.32%** (2,382,727 extra stored bytes).

The temporary requested-byte total increases rather than decreases
(0.915 MiB → 1.458 MiB), while allocator time stays roughly flat. This is
consistent with more, smaller literal chunks creating more per-chunk objects/calls
while reducing the amount of literal entropy work decoded for a region. The
instruction delta is the requested coarse layer cut; it is not an additive
sub-function timing decomposition.

## DCtx audit

The current ACE region path calls one-shot `ZSTD_decompress()` from
`lit_range()` and `fse_range()`. The pinned zstd 1.5.7 implementation uses a
transient `ZSTD_DCtx` for that one-shot call under its default heap mode: create
context, decompress, free context. Therefore the current region path does **not**
reuse a persistent DCtx across requests, and can pay that fixed context cost once
per touched zstd chunk.

No persistent-DCtx optimization was attempted here.
