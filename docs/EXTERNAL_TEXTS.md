# Правило подписи внешних текстов

Яков, 25.11.2026. Правило для HW; применять всегда.

1. Любой текст для чужих людей, который пишешь ты (issue, PR, комментарий,
   письмо, черновик для Якова), начинается с первой строки ровно:

   ```text
   [written by ChatGPT (AI) at the author's request; checked by the author]
   ```

2. Если текст писал Claude, строка та же, но с `Claude (AI)`. Чужую подпись
   не ставить:

   ```text
   [written by Claude (AI) at the author's request; checked by the author]
   ```

3. Простое «спасибо» без содержания — без подписи.

4. Hacker News — никаких текстов от ИИ, даже черновиков: только опорные
   пункты по-русски для Якова.

5. Ты только готовишь черновик. Отправляет Яков или контролёр по его слову,
   после проверки чисел.
