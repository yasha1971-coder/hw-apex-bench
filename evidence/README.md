# Benchmark evidence

`stage1-20260909/receipt.json` binds the published report and six raw query files to the tested benchmark commit, corpus MD5 and successful GitHub Actions run.

The six files preserve 200 latency samples and 200 separate amplification samples for each of the three codecs. Their SHA-256 digests were checked after retrieval, and p50/p99 and amplification were recomputed from those files. No timing sample was removed.

The root README and results.jsonl are the report generated by that run. Commands, versions, hardware, archive hashes and the exact ACEAPEX SHA accompany the measurements. This directory keeps the raw samples available after the workflow artifacts expire.
