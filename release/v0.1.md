# hw-apex-bench v0.1

First release of the adapter-based compressed-access benchmark: BGZF, zstd-seekable,
ACEAPEX and blocked XZ. Nine measurement axes, adapter capability declarations with
explicit unsupported reasons, resident library region contexts and byte-exact
adapter qualification are implemented. See ADAPTERS.md and CONTRIBUTING.md.

Start with `./run.sh --check codecs/xz.sh`; further examples are in ADAPTERS.md.
Use the explicit
`--check`, `--plan` and `--measure` entry points for the new interface. The
no-argument entry point still invokes the historical runner.

The published 435 JSONL records are preserved byte for byte (SHA-256
`cb52b8cb9fac484a6474d976681ea85ae2c052d80d820422b7f57c25ec938100`).
The completed native full run produced 236 new records and 145 raw files:
98/101 deterministic comparisons matched initially; the three BGZF differences
were resolved by the separately archived, untimed libdeflate build audit.
These are complementary proofs, not a rewritten 101/101 full-run receipt.
Timing values are machine-dependent and were not required to match byte for byte.

The full comparison covers the original three CPU formats/four configurations.
XZ has separate correctness and small-corpus nine-axis evidence; it is not a new
full-corpus performance row in the historical table. Historical CPU, strict c(g)
and owner-declared GPU scopes remain separate. No benchmarks were rerun for release.

Release assets include the exact source archive, the original full-run artifact
and SHA256SUMS. Full-run artifact: workflow 34619124537, artifact 10273026378,
SHA-256 `3fb9531d64518b0c5c1e61968eae80a374ae4da0285ce0178555ff7fa87dc390`.
The canonical BGZF audit is committed under evidence/bgzf-libdeflate-20260911/:
workflow 34626693337, artifact 10273679252. See review/BGZF_BACKEND_REVIEW.md.
